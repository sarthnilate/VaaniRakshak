# Dataset Card

Status: **NOT YET POPULATED — no datasets have been collected or generated.**

This file will document, for every dataset used in training or evaluation
(Rules.md section 5):

- source
- license / permission status
- version
- language
- speaker information (as legally appropriate)
- label (bona fide / synthetic / voice-conversion / etc.)
- generation family (if synthetic)
- preprocessing applied
- split (train / val / test), speaker-disjoint and generator-disjoint where applicable

Populated starting Phase 2 (Dataset & Evidence Infrastructure). Until then,
no dataset claims should be treated as true.
