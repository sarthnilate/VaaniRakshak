# Model Card

Status: **NOT YET POPULATED — no models have been trained or evaluated.**

This file will document, per model (voice authenticity, speaker
verification, STT, conversation intelligence, temporal risk):

- architecture and version
- training data (linked to DATASET_CARD.md)
- intended use and out-of-scope use
- measured metrics (precision, recall, F1, ROC-AUC/PR-AUC, EER where
  appropriate, latency, per-language performance) with the exact
  evaluation conditions
- known failure modes and limitations

Populated starting Phase 3 (Voice Authenticity Model) and updated through
Phase 13 (Multilingual Expansion). No accuracy or performance number should
be treated as real until it appears here with reproducible conditions
(Rules.md section 7, section 18).
